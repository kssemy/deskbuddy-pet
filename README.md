# 일하는 캐릭터 시제품

Windows에서 캐릭터가 투명한 창으로 바탕화면 위를 움직이는 첫 테스트 버전입니다.

## 실행

`run.cmd`를 더블클릭하거나 이 폴더에서 `npm start`를 실행합니다. 처음 실행하는 PC에서는 `npm install`이 필요합니다. 별도 `.exe` 빌드는 필요하지 않습니다.

## 지금 시험할 수 있는 것

- 캐릭터 자동 이동, 드래그. 내 캐릭터와 친구 캐릭터 모두 듀얼 모니터와 화면 끝까지 이동
- 캐릭터 클릭 → 위쪽으로 늘어나는 말풍선 체크리스트
- 넓은 TO DO 창 높이 슬라이더와 전체 TO DO 공개 체크
- 캐릭터 옆 `···` 버튼 → 한마디 입력. 등록한 문구는 캐릭터 위에 표시
- 미완료 할 일은 날짜가 바뀌어도 유지. 완료한 할 일은 설정에 따라 아래로 이동하거나 목록에서 숨김 (기록은 유지)
- 할 일 옆 압정을 누르면 목록 맨 위에 고정. 고정 할 일은 완료 후에도 취소선이 유지됨
- 이전 버전의 `고정 할 일` 항목은 시작할 때 압정 항목으로 옮겨짐
- 설정의 `이번 달 한 일 보기`에서 날짜별 체크리스트와 근무시간, 캐릭터 변경 기록 확인. 기록된 그림을 누르면 다시 선택할 수 있습니다.
- `캐릭터 옷장`에서 올린 PNG를 피드처럼 보고 다시 선택하거나 삭제할 수 있습니다.
- 화면 오른쪽 위 `↥` 버튼으로 맨 위 표시를 갱신하고, `🏠` 버튼으로 모든 캐릭터를 우측 상단에 모읍니다. 다시 누르면 원래 위치로 돌아갑니다.
- Windows 작업 표시줄에 앱 버튼이 표시됩니다. 버튼을 눌러 돌아오면 캐릭터 창을 다시 앞으로 올립니다.
- 맨 위 표시를 3초마다 복구합니다. 실행할 때 새 버전을 자동 적용하고, 사용 중에는 작업 표시줄에서 앱으로 돌아올 때 확인해 새 버전이 나오면 재시작 버튼을 띄웁니다. 잦은 전환 때는 1분 안에 다시 확인하지 않습니다.
- 우클릭 `설정`에서 기본 PNG를 올리고, `AI로 모션 추가하기`에 행동을 적으면 동작 3종을 한 세트로 생성·등록할 수 있습니다. API 키가 필요하며 사용료가 발생할 수 있습니다. 기본 PNG와 생성된 동작의 불투명한 바깥 배경은 자동으로 제거합니다. 동작은 최대 12장까지 등록되며 순서대로 잠깐 나타난 뒤 기본 PNG로 돌아갑니다.
- 내 화면의 모든 캐릭터 크기를 함께 조절 (80~170px). 업로드 PNG의 원본 해상도는 표시 크기에 영향을 주지 않습니다.
- 캐릭터 우클릭 → 설정 또는 종료

PNG와 체크리스트는 이 PC의 Electron 사용자 데이터 폴더에 저장됩니다. 전체 TO DO 공개를 켜면 현재 목록의 할 일이 친구에게 공유됩니다.
PNG를 올리지 않으면 포함된 노란 캐릭터가 기본으로 나타납니다. 내 캐릭터 우클릭으로 위치를 고정하거나 자동 이동을 다시 켤 수 있습니다.

출근·점심·퇴근 시각은 우클릭 설정에서 바꿉니다. 캐릭터 앱 계정에 연결한 경우 시간 설정은 계정에도 저장되어 다른 PC에서 같은 계정으로 로그인하면 적용됩니다. 캐릭터 아래 타이머는 앱 실행 시간과 관계없이 설정한 출근·퇴근 시각으로 계산합니다. 점심시간에는 시간 대신 '점심 먹는 중'만 표시하고, 업무 타이머에서는 점심시간을 제외합니다. 앱의 켜짐·꺼짐 기록은 별도로 로컬에 남습니다.

월간 캘린더의 근무시간은 앱을 켠 날의 설정된 출퇴근시간(점심 제외)을 기본으로 계산합니다. 퇴근 이후 앱을 계속 켜 두면 그날 앱을 끈 시각까지 야근을 더합니다.

## 친구와 함께 일하기

Supabase에는 [supabase-pet.sql](supabase-pet.sql)과 [supabase-pet-schedule.sql](supabase-pet-schedule.sql)을 적용했습니다. 우클릭 → 설정 → 함께 일하기에서 원하는 닉네임과 숫자 PIN 6자리를 정해 `처음 가입`을 누르세요. 다음부터는 같은 정보로 로그인합니다. 기존 Workbuddy 계정은 사용하지 않습니다. PIN은 저장하지 않고, 연결 세션은 Windows 암호화 저장소를 통해 이 PC에 보관됩니다.

연결한 앱이 켜져 있는 친구의 PNG와 공개 TO DO가 표시됩니다. 친구 캐릭터를 클릭하면 공개 TO DO가 열리고 닫힙니다. 친구를 드래그하면 내 화면에서 위치가 옮겨지고 계속 자동 이동하며, 우클릭으로만 고정할 수 있습니다. 친구 캐릭터를 세 번 빠르게 누르면 양쪽 화면에서 짧게 한 번 흔들립니다. 내 캐릭터 옆 작은 점을 누르면 양쪽 화면에서 1초간 빛납니다. 두 캐릭터가 내 화면에서 만나면 하이파이브가 한 번 나타나며, 떨어졌다 다시 만나면 반복될 수 있습니다. 앱을 끄면 캐릭터를 제거하고, 비정상 종료 때는 마지막 접속 40초 후 사라집니다.

설정의 연결 상태에는 현재 화면에 나타나는 친구 수가 함께 표시됩니다. 친구가 없으면 `나만 접속 중`, 서버 확인 중에는 `친구 확인 중…`으로 표시합니다.
