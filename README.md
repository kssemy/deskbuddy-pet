# 일하는 캐릭터 시제품

Windows에서 캐릭터가 투명한 창으로 바탕화면 위를 움직이는 첫 테스트 버전입니다.

## 실행

`run.cmd`를 더블클릭하거나 이 폴더에서 `npm start`를 실행합니다. 처음 실행하는 PC에서는 `npm install`이 필요합니다. 별도 `.exe` 빌드는 필요하지 않습니다.

## 지금 시험할 수 있는 것

- 캐릭터 자동 이동, 드래그
- 캐릭터 클릭 → 위쪽으로 늘어나는 말풍선 체크리스트
- 넓은 TO DO 창 높이 슬라이더와 전체 TO DO 공개 체크
- 캐릭터 옆 `···` 버튼 → 한마디 입력. 등록한 문구는 캐릭터 위에 표시
- 미완료 할 일은 날짜가 바뀌어도 유지. 완료한 할 일은 설정에 따라 아래로 이동하거나 목록에서 숨김 (기록은 유지)
- 할 일 옆 압정을 누르면 목록 맨 위에 고정. 고정 할 일은 완료 후에도 취소선이 유지됨
- 이전 버전의 `고정 할 일` 항목은 시작할 때 압정 항목으로 옮겨짐
- 설정의 `이번 달 한 일 보기`에서 날짜별 체크리스트와 근무시간, 월간 총 근무시간 확인
- 화면 오른쪽 위 `↥` 버튼으로 캐릭터를 맨 위로 갱신
- 설정의 `최신 버전 확인하기`에서 GitHub 배포 버전과 비교하고, 새 버전이 있으면 다운로드 페이지 열기
- 우클릭 `설정`에서 기본 PNG와 동작 PNG(최대 12장)를 따로 등록. 동작 PNG는 순서대로 잠깐 나타난 뒤 기본 PNG로 돌아갑니다.
- 크기 조절 (80~170px)
- 캐릭터 우클릭 → 체크리스트, 설정 또는 종료

PNG와 체크리스트는 이 PC의 Electron 사용자 데이터 폴더에 저장됩니다. 전체 TO DO 공개를 켜면 현재 목록의 할 일이 친구에게 공유됩니다.

출근·점심·퇴근 시각은 우클릭 설정에서 바꿉니다. 캐릭터 아래 타이머는 앱 실행 시간과 관계없이 설정한 출근·퇴근 시각으로 계산합니다. 점심시간에는 시간 대신 '점심 먹는 중'만 표시하고, 업무 타이머에서는 점심시간을 제외합니다. 앱의 켜짐·꺼짐 기록은 별도로 로컬에 남습니다.

월간 캘린더의 근무시간은 앱을 켠 날의 설정된 출퇴근시간(점심 제외)을 기본으로 계산합니다. 퇴근 이후 앱을 계속 켜 두면 그날 앱을 끈 시각까지 야근을 더합니다.

## 친구와 함께 일하기

Supabase에는 [supabase-pet.sql](supabase-pet.sql)을 적용했습니다. 우클릭 → 설정 → 함께 일하기에서 원하는 닉네임과 숫자 PIN 6자리를 정해 `처음 가입`을 누르세요. 다음부터는 같은 정보로 로그인합니다. 기존 Workbuddy 계정은 사용하지 않습니다. PIN은 저장하지 않고, 연결 세션은 Windows 암호화 저장소를 통해 이 PC에 보관됩니다.

연결한 앱이 켜져 있는 친구의 PNG와 공개 TO DO가 표시됩니다. 친구 캐릭터를 클릭하면 공개 TO DO가 열리고 닫힙니다. 드래그한 친구의 위치는 내 화면에만 적용되고 고정됩니다. 친구 캐릭터를 세 번 빠르게 누르면 친구 화면에서 1초간 흔들립니다. 내 캐릭터 옆 작은 점을 누르면 양쪽 화면에서 1초간 빛납니다. 두 캐릭터가 내 화면에서 만나면 서로의 화면에 하이파이브가 잠깐 나타납니다. 앱을 끄면 캐릭터를 제거하고, 비정상 종료 때는 마지막 접속 40초 후 사라집니다.
